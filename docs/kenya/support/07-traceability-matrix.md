**Evidence class**

| Class | Meaning |
|---|---|
| **A** | An automated test in the repository targets the change (manual evidence may also exist) |
| **M** | Manual or QA-kit evidence only |
| **N** | No evidence found |

**Columns**

- *Automated evidence* — test files in the repository. The UI suites (192 + 316 tests) were run on 13 Oct; the Java suites run in the image build and were not run on the release machine; the Playwright suite was not run for this release.
- *Manual / QA evidence* — QA-kit scripts and results (kits are under the release engineer's `~/Desktop/CCRS-QA/`, not in git) and PR descriptions.
- *cms-pilot 14 Oct* — exercised end to end on cms-pilot while recording this package's videos (officers EMP130 and EMP048, test resident 711000101). "PASS" = the step completed and the server status was checked; "seen" = shown on screen without a status change.
